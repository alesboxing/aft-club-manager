# Передача работы: AFT Bracket System, состояние на v475

## Что где лежит
- `AFT_v495_edit.html` — рабочий основной файл. Внутри него вшиты регистрация (киоск) и шаблон файла информатора.
- `AFT_registration_kiosk.html` — тот же киоск отдельным файлом (копия вшитого; скачивается из основного кнопкой «📲 Скачать регистрацию»).
- `AFT_тест_регистрация_2-64.json` — тестовая регистрация: 63 категории по 2…64 спортсмена (2079 человек), с регалиями и международными встречами.
- `tests/` — автотесты (Python + Playwright), запуск: `python tests/<файл>.py AFT_v495_edit.html`.
- Правило: каждая версия — новый файл `AFT_vNNN_*.html`; в основном файле нельзя менять логику без теста.

## Регистрация и информатор (новое)
- Формат файла регистрации: `{format:'aft-registration',version:1,records:[{lastName,firstName,middleName,fio,gender:'M'|'F',birthDate,birthYear,weight,club,city,coach,rank,yearsBoxing,bouts,wins,intlBouts,intlWins,noRecord,achievements,registeredAt}]}`. Загружается в основной файл кнопкой «Загрузить JSON» (она сама различает резервную копию и регистрацию). Дубли пропускаются по ФИО + год.
- Данные для информатора хранятся в `athlete.info` и в `note` («Разряд…; стаж…; боёв…, побед…, международных…, побед в них…. Достижения: …»); запасной разбор `note` есть.
- Файл информатора создаётся кнопкой «🎙️ Файл информатора» на день, выбранный на вкладке «Пары». Требует, чтобы все категории были прожеребьены. Тренер читается именем как введён («Тренер: …»): склонять фамилии автоматически нельзя без ошибок.
- Паспортные данные детей киоск намеренно не собирает.

## Правила работы
- Новый баг → сначала красный тест, потом исправление, потом полный прогон.
- Если тест прошёл подозрительно легко — проверить мутацией (сломать правку и убедиться, что тест краснеет).
- Не выпускать версию без зелёных тестов изменённой области.
